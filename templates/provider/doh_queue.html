ℹ DOH Report Queue — How This Works
What this screen does
📋Full list of all open DOH reports waiting for submission. Every record was auto-created when a qualifying lab result was finalized — no manual entry.
🆌Filter by state, condition, or status to work in batches. Overdue records appear at the top with a red row background.
📧Select multiple records and bulk-fax them in one action — each goes to its individually configured state/county fax number via the platform's e-fax integration.
Workflows this solves
🔴Previously: Previously: no queue view. Coordinators worked from emails or spreadsheets to track what needed to be sent.
🟢Now: Now: every open obligation is in one place, sortable and filterable, with SLA status visible at a glance.
🔴Previously: Previously: faxing required a physical machine and had no confirmation logging.
🟢Now: Now: e-fax sends electronically within the platform. Confirmation is logged automatically on each record.
Key design decisions
⚠Overdue rows show in red and sort to the top — prioritize these first.
🔓Patient column shows masked ID only (PT-••••-XXXX) — no name or DOB in the queue list.
✅Bulk fax uses each record's own configured destination — not a shared number.
