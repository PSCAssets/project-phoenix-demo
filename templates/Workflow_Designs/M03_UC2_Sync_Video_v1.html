📹
Video-Only: Pre-Visit Setup Check
Video consultations require a camera and microphone setup check before the patient can join. The setup check is accessible from the appointment card in the patient portal. Patient is prompted to run the check in the 1-hour reminder notification. If setup fails, patient is directed to troubleshooting steps and care team contact. Setup check tool: TBD (open question — determine if built-in portal feature or third-party tool e.g., Twilio pre-flight).

🔷 M06 Workflow Engine items for video: Scheduled reminder automation (24hr + 1hr with setup check link), real-time queue SLA clock, provider selection → patient immediate alert, patient join window timer, post-session SLA stop. All must be captured in M06 BRD.
📹 Video setup check (open item): Determine whether the camera/microphone setup check is a built-in portal feature or a third-party tool (e.g., Twilio pre-flight check). Required before scheduling and before joining real-time queue. Engineering to confirm approach.
⚠️ Real-time path key difference from telephonic: Video real-time requires setup check BEFORE queue entry (not after provider selection) — because video cannot start if patient setup fails. Telephonic real-time setup is just phone number confirmation.
