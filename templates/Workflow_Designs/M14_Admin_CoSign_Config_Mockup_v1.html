Co-Sign Configuration
Configure co-sign routing rules per care product. When enabled, non-physician provider notes are held for physician review before finalization.
How co-sign routing works Co-sign is a care product-level setting. When enabled, the routing rule defines which provider role submits for co-sign and which physician role receives the request. Disabling co-sign for a care product means provider notes finalize immediately without physician review.
