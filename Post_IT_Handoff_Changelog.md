### 2026-07-22 (bug fix — dead buttons on 5 role dashboards)

**No requirement change — JavaScript bug fix.** Justin reported that no buttons worked on the QA Reviewer dashboard on the live site (Approve/Reject/Clarify/Review Docs all silently did nothing). Root cause: `templates/provider/qa_reviewer_dashboard.html`'s `URGENT_MSGS` array (URG-MSG-001) had an unescaped apostrophe inside a single-quoted JS string (`...they're asking...I don't have authority...`), which terminates the string early and throws a syntax error — and one syntax error anywhere in a `<script>` block prevents the *entire* block from running, so every function on the page (`approveQA`, `rejectQA`, `clarifyQA`, `openReview`, `filterChip`, etc.) was undefined and every onclick silently failed.
Checked whether this was isolated to this one page — it wasn't. The same copy-pasted `URGENT_MSGS` block with the same unescaped apostrophes was in **5 dashboards**: `manager_dashboard.html`, `np_dashboard.html`, `rn_dashboard.html`, `ma_dashboard.html`, and `qa_reviewer_dashboard.html`. 4 other dashboards that share this block (`dashboard.html`/MD, `gc_dashboard.html`, `gca_dashboard.html`, `doh_dashboard.html`) already had it correctly escaped — this matches a prior fix noted for the GC dashboard specifically that never got propagated to the other copies. Fixed all 5, then ran a real `node --check` syntax scan across every `<script>` block in all 191 template files to confirm no other instance of this exists; the one other hit was a false positive (Jinja `{% raw %}{{ var }}{% raw %}` syntax the checker can't parse pre-render, not a real JS bug).
**Practical impact:** every button on Manager, NP, RN, MA, and QA Reviewer dashboards has likely been non-functional in the demo for some time — this wasn't a today-only regression, it predates this round of changes. Worth doing a quick click-through on all 5 once deployed to confirm.
