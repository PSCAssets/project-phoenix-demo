The Engine Behind the Scenes

How the platform is configured once and then runs every consult automatically from start to finish

🎛️

The Cockpit — Configured Once, Applied Every Time

Set by the Admin Portal. Powers every automated decision in the pipeline below.

🏥
Care Programs
Defines what each telehealth program looks like, what patients need to qualify, how the visit runs and how it is billed.
🗺️
State Coverage Rules
Controls which programs are available in each state and what requirements must be met before a patient can be seen.
⏱️
Response Time Standards
Sets how quickly each step in the journey must be completed and what the platform does automatically when a deadline is at risk.
👥
Team and Oversight Rules
Determines which team handles which type of work, who has oversight and when a second review is required before a consult can close.
🔀
Patient Journey Paths
Configures the specific steps each patient follows based on their program so every journey is consistent and nothing falls through the cracks.
🔔
Communication Rules
Defines when patients and providers are automatically contacted so everyone stays informed throughout the journey without anyone having to reach out manually.
↓ Rules power every automated step below ↓
